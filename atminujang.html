📤 Export

CSV Kastamer — data master kastamer saja (nama, HP, wilayah, alamat, koordinat, catatan, link Maps). Cocok untuk diedit di spreadsheet atau import kastamer baru.

JSON Backup — full backup semua data (kastamer, pesanan, wilayah, histori status). Gunakan untuk backup rutin atau pindah perangkat.

📥 Import CSV

Upload file .csv untuk menambah atau mengganti data kastamer. Format yang didukung: header baris pertama. Kolom wajib: Nama dan No. Telepon. Kolom opsional: Wilayah, Alamat, Pesanan, Pembayaran, Status, Catatan.

Atau paste teks CSV:
🔧 Petakan Kolom CSV

♻️ Restore dari JSON Backup

Upload file JSON backup untuk mengembalikan semua data. Akan mengganti seluruh data yang ada.

🗑️ Reset Data

Hapus semua data kastamer. Tidak bisa dibatalkan. Pastikan sudah backup JSON terlebih dahulu.

🎟️ Tambah Kode Promo

Buat kode promo yang bisa dipakai kastamer di toko. Kode disimpan ke Firestore collection promo_codes (Document ID = kode, otomatis HURUF KAPITAL).

Catatan: field kg/subtotal/kuota yang kosong dianggap tanpa batasan. Menyimpan kode yang sudah ada akan menimpa datanya (usedCount di-reset ke 0).
